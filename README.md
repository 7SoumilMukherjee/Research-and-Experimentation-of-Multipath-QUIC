# Multipath QUIC (MPQUIC)

This repository contains the implementation, validation, and experimental evaluation of the Multipath QUIC (MPQUIC) protocol carried out by **Soumil Mukherjee** during a research internship at the **Centre for Networked Intelligence (CNI) Lab**, Department of Electrical Communication Engineering, **Indian Institute of Science (IISc), Bengaluru**.

The work focuses on understanding the architecture and behaviour of MPQUIC through its implementation and experimental evaluation under a variety of network conditions. The protocol was studied using both virtual and physical network testbeds, with experiments conducted under baseline conditions, heterogeneous path delays, bandwidth heterogeneity, and path failure scenarios.

## Repository Structure

- **`code/`** – Source code of the CoNEXT'17 MPQUIC implementation, build instructions, and implementation details.
- **`reports/`** – Final internship report, LaTeX source, and processed packet capture archives used for protocol analysis.
- **`presentations/`** – Presentation slides related to the internship work.

For detailed information about each component, please refer to the respective `README.md` files within each directory.
